# Bundled benchmark data

The JSON files in this directory are generated by `benchmarks/download.py`
and consumed by `evaluate.py`. They are committed so evaluation is fully
offline and reproducible without any extra download step.

## Sources & licenses

| File               | Source                                                                 | Notes                                        |
| ------------------ | ---------------------------------------------------------------------- | -------------------------------------------- |
| `aime2025.json`    | [opencompass/AIME2025](https://huggingface.co/datasets/opencompass/AIME2025) | AIME 2025 I + II (30 problems)           |
| `gpqa_diamond.json`| [fingertap/GPQA-Diamond](https://huggingface.co/datasets/fingertap/GPQA-Diamond) (ungated mirror of [Idavidrein/gpqa](https://huggingface.co/datasets/Idavidrein/gpqa)) | CC-BY-4.0 |
| `livecodebench.json` | [livecodebench/code_generation_lite](https://huggingface.co/datasets/livecodebench/code_generation_lite) via the LightEval parquet mirror | MIT, release v1 subset |

If you have accepted the GPQA terms and set `HF_TOKEN`, running the
downloader again will pull the official `gpqa_diamond.csv` (with cleanly
rendered A–D options) instead of the mirror.

## Regenerating

```bash
python -m benchmarks.download --aime-limit 30 --gpqa-limit 198 --lcb-limit 12
```

AIME answers are the official exam answers (integers 0–999). LiveCodeBench
correctness is checked by executing the generated program against the
official public and (decoded) private test cases. GPQA correctness is
checked against the official answer key.
